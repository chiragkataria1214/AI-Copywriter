# Jones Road Beauty Meta Ad Generator

A comprehensive AI-powered content generation platform designed specifically for Jones Road Beauty's marketing needs. This enterprise-grade application leverages Anthropic's Claude AI with sophisticated prompt engineering to generate brand-compliant marketing content across multiple channels and formats.

## 🚀 Core Features & Capabilities

### 1. **Paid Social Media Generation**

#### Ad Copy Station
- **Multi-Framework Headlines**: Generates compelling Facebook/Instagram ad headlines using 15+ proven frameworks
  - Benefit-driven headlines
  - Problem-solution positioning  
  - Curiosity-gap frameworks
  - Social proof integration
  - Seasonal/trending hooks
- **Primary Text Generation**: Creates conversion-optimized ad copy with:
  - Brand voice consistency (adjustable brand/DR balance)
  - Persona-specific messaging
  - Product claim compliance
  - CTA optimization
  - Length customization (short, medium, long formats)

#### Static Ad Analysis Station  
- **AI-Powered Image Analysis**: Upload static ad images for intelligent copy extraction

- **Copy Optimization**: Provides improvement suggestions based on brand guidelines

#### Landing Page Copy Station

#### State Management
- **TanStack Query**: Server state management with caching and synchronization
- **React Context**: Global application state for user preferences and configuration
- **Custom Hooks**: Specialized hooks for form management, API calls, and UI state
- **Local Storage**: Persistent user preferences and session data

#### Form Management
- **React Hook Form**: Type-safe form handling with validation
- **Zod Validation**: Schema-based input validation and type safety
- **Real-time Validation**: Immediate feedback on input requirements
- **Auto-save**: Prevents data loss during generation processes


## 🚦 Installation & Setup

### Prerequisites
- **Node.js 18+**: JavaScript runtime environment
- **PostgreSQL 14+**: Database server (local or cloud)
- **Anthropic API Key**: Claude AI access
- **Git**: Version control system

### Step-by-Step Installation

#### 1. Repository Setup
```bash
# Clone the repository
git clone <repository-url>
cd jones-road-meta-ad-generator

# Install all dependencies
npm install
```

#### 2. Environment Configuration
```bash
# Create environment file
cp .env.example .env

# Edit with your configuration
nano .env
```

#### 3. Database Setup
```bash
# Push database schema to PostgreSQL
npm run db:push

# Initialize AI prompts and configuration
npm run init-prompts

# Seed products and frameworks (optional)
npm run seed-products
npm run seed-frameworks
```

#### 4. Development Server
```bash
# Start development server with hot reload
npm run dev

# Server will be available at http://localhost:5000
```

#### 5. Production Deployment
```bash
# Build for production
npm run build

# Start production server
npm start
```

### Docker Deployment (Optional)
```dockerfile
# Dockerfile example
FROM node:18-alpine

WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production

COPY . .
RUN npm run build

EXPOSE 5000
CMD ["npm", "start"]
```

#### Development Commands
```bash
npm run dev          # Start development server with hot reload
npm run check        # TypeScript type checking across entire codebase
npm run lint         # ESLint code quality checking
npm run format       # Prettier code formatting
```

#### Database Management
```bash
npm run db:push      # Push schema changes to database
npm run db:studio    # Open Drizzle Studio for database management
npm run init-prompts # Initialize default AI prompts and configuration
npm run seed-products # Seed product database with Jones Road catalog
npm run fix-products # Utility script for product data cleanup
npm run cleanup-products # Remove duplicate or invalid products
```

#### Production Commands
```bash
npm run build        # Build frontend and backend for production
npm start           # Start production server
npm run preview     # Preview production build locally
```

#### Testing Commands
```bash
npm test            # Run test suite
npm run test:watch  # Run tests in watch mode
npm run test:coverage # Generate test coverage report
```

### Code Organization Principles

#### TypeScript Configuration
- **Strict Mode**: Full TypeScript strict mode enabled
- **Path Mapping**: Absolute imports with @ prefix for cleaner imports
- **Shared Types**: Common interfaces in `/shared` directory
- **Type Safety**: 100% type coverage across frontend and backend

#### Component Architecture
- **Single Responsibility**: Each component has one clear purpose
- **Composition over Inheritance**: Favor component composition
- **Props Interface**: Explicit TypeScript interfaces for all component props
- **Custom Hooks**: Business logic extracted into reusable hooks

#### API Design Patterns
- **RESTful Endpoints**: Standard HTTP methods and status codes
- **Consistent Response Format**: Standardized API response structure
- **Error Handling**: Comprehensive error responses with user-friendly messages
- **Validation Middleware**: Input validation at API boundary

## 🔌 API Documentation

### Authentication Endpoints
```typescript
POST /api/login
// User authentication with username/password
Body: { username: string, password: string }
Response: { user: User, session: string }

POST /api/logout
// End user session
Response: { success: boolean }

GET /api/me
// Get current user information
Response: User | { error: "Not authenticated" }

POST /api/verify-admin-key
// Verify admin key for AI settings access
Body: { adminKey: string }
Response: { success: boolean }
```

### Content Generation Endpoints
```typescript
POST /api/generate-ad-copy
// Generate Facebook/Instagram ad copy
Body: {
  transcription?: string,
  customBrief?: string,
  concept: string,
  targetAudience: string,
  landingPageUrl?: string,
  brandDrBalance: number,
  selectedProduct?: string,
  selectedProducts?: string[],
  uploadedImage?: string
}
Response: {
  copyId: string,
  headlines: Array<{ framework: string, copy: string }>,
  primaryText: string,
  debugInfo?: object
}

POST /api/generate-landing-page-copy
// Generate landing page content
Body: {
  landingPageType: string,
  productBrief: string,
  mainAngle: string,
  concept: string,
  brandDrBalance: number,
  selectedProducts: string[],
  useAdsForLanding: boolean,
  adsContent?: string
}
Response: {
  copyId: string,
  generatedCopy: string,
  debugInfo?: object
}

POST /api/generate-retention-copy
// Generate email/SMS retention content
Body: {
  keyMessage: string,
  platform: "Email" | "SMS",
  emailType?: string,
  selectedFramework?: object,
  selectedProducts?: string[],
  audience: string,
  goal: string,
  contentLength: string,
  keywordsToInclude?: string[],
  wordsToAvoid?: string[]
}
Response: {
  copyId: string,
  generatedCopy: string,
  debugInfo?: object
}

POST /api/generate-social-captions
// Generate organic social media captions
Body: {
  contentType: string,
  transcription: string,
  platform: string,
  goal: string,
  tone: string,
  variations: number,
  selectedProduct?: string,
  selectedProducts?: string[],
  concept: string
}
Response: {
  copyId: string,
  captions: string[],
  debugInfo?: object
}

POST /api/generate-story-sequence
// Generate Instagram story sequences
Body: {
  contentType: string,
  transcription: string,
  sequenceType: string,
  length: number,
  tone: string,
  selectedProduct?: string,
  selectedProducts?: string[],
  concept: string
}
Response: {
  copyId: string,
  storySequence: Array<{
    slideNumber: number,
    content: string,
    visualDirection: string,
    interactiveElement?: string
  }>,
  debugInfo?: object
}

POST /api/analyze-static-ad
// Analyze uploaded static ad images
Body: {
  imageFile: File,
```

### Configuration Management Endpoints
```typescript
GET /api/training-config
// Get current AI training configuration
Response: TrainingConfig

PUT /api/training-config
// Update AI training configuration (Admin only)
Body: Partial<TrainingConfig>
Response: { success: boolean, config: TrainingConfig }

GET /api/products
// Get all products
Response: Product[]

GET /api/products/active
// Get active products only
Response: Product[]

POST /api/products
// Create new product (Admin only)

Response: Product

GET /api/products/:productId/claims
// Get product claims
Response: ProductClaim[]

POST /api/products/:productId/claims
// Add product claim (Admin only)

GET /api/personas
// Get all customer personas

GET /api/personas/:personaId/pillars

Response: PersonaPillar[]

GET /api/email-frameworks/active
// Get active email frameworks

GET /api/landing-page-frameworks/active
// Get active landing page frameworks
```
